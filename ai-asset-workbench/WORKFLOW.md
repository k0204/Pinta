# 元素抠图与无痕还原调研

## 结论

“完美抠图”不是单个按钮能保证的结果，尤其是细草、半透明花瓣、逆光边缘和水面倒影。可复用的可靠流程是：

`高质量分割模型 → 人工边缘修补 → 去色边 → 光照/色彩匹配 → 非破坏合成 → 100% 检查`

工作台把流程拆成五步。第 1 步必须先在画布上框选或点击区域，再确认 SAM 2 返回的对象遮罩；SAM 2 失败时不会把矩形选框伪装成前景，可改用“自动抠图”本地启发式流程。联网生成遵循上层项目已有的 `POST /api/images` + job 轮询协议，Nano Banana 只接收局部补全提示和参考图。

本机已安装官方 SAM 2 包到 `H:\AISpine\AIModel\sam2`，并下载 `sam2_hiera_base_plus.pt` 到 `H:\AISpine\AIModel\models\sam2`。现有 CUDA Python 环境为 `H:\AISpine\AIModel\venv`；权重已用 `build_sam2` 成功加载到 `cuda:0`。

## 模型选择

| 目标 | 推荐 | 适用场景 |
| --- | --- | --- |
| 通用主体抠图 | `rembg`（U²-Net / IS-Net） | 人物、动物、单个物体；本地部署简单 |
| 复杂细节 | SAM 2 / SAM + 边缘细化 | 枝叶、镂空、多个相邻元素；需要点选或框选提示 |
| 云端快速结果 | remove.bg / Clipdrop | 不想维护 GPU；要接受上传成本和隐私边界 |
| 生成替代元素 | Nano Banana（上层 `/api/images` provider）或 GPT Image | 用文字保持风格、视角、色温；必须人工筛选 |

对示例湖畔图，建议把前景草花作为一个组先分割，再单独修整花朵、叶片和阴影。不要把水面倒影放进透明资产，否则还原时会出现双重反射。

## 边缘质量检查

1. 在棋盘格背景上放大到 200% 检查白边/黑边。
2. 用 2–8 px 羽化处理硬切边；细枝不要用过大的羽化半径。
3. 对逆光区域做去色边（decontaminate），把原背景的黄绿色污染压回对象颜色。
4. 保留原始 PNG 和遮罩，避免先导出 JPG 再回贴。
5. 合成后在原图缩放比例和 100% 各看一次，确认阴影方向、色温、锐度和噪点一致。

## 生成与还原提示词

生成提示词应同时描述对象、艺术风格、镜头位置、光照和透明背景，例如：

> 同一幅复古数字绘景风格，一簇湖畔野花与细长草叶，暖金色夕阳从右后方照射，保留自然投影方向，透明背景，边缘清晰，不要天空、山脉和水面。

将生成结果作为参考图，而不是直接覆盖原图。最终位置、比例和混合模式在合成步骤完成；这能保留原场景的透视和颗粒感，减少“贴纸感”。

## 服务接入边界

工作台复用上层项目的 `/api/images`、`/api/chat` 和 `/api/images/jobs/{id}` 协议，不在浏览器直接拼接供应商 URL。服务端负责 provider、Nano Banana channel、计费、重试和凭据；浏览器只保存当前会话 Token。SAM 2 / Matte Anything 没有在现有 `doc/api.md` 中声明专用端点，因此目前由画布选择与本地 alpha fallback 承担，后续若服务端增加 provider 可直接接入同一 job 轮询层。

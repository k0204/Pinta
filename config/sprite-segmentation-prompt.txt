分析输入的角色精灵图集，检测、裁剪并对齐其中的每一个角色方向图。

这些图片属于同一个角色、同一个静止动作，但朝向不同。目标是将它们拆分成独立图片，并在游戏中切换方向时保持角色脚底位置稳定，不发生水平或垂直跳动。

坐标与检测规则：
1. 必须按输入 PNG 的原始画布坐标分析，不得缩放、旋转或重新采样图像。提示词末尾会给出已知的实际画布宽高，必须原样返回这两个值，不得根据可见内容、模型预览尺寸或内部缩放结果猜测 image_width 和 image_height。
2. 使用像素坐标系，原点为整张图像左上角，x 向右增大，y 向下增大。
3. 检测图集中所有不同的角色图片，不得遗漏、重复或合并相邻角色。
4. 按视觉行分组：先从上到下排列各行，再在同一行内从左到右排列。
5. index 按上述阅读顺序从 0 开始连续编号。
6. 同一角色图片中的头发、武器、衣物、饰品、轮廓、抗锯齿边缘、与身体分离的小块像素，以及属于该帧的阴影或特效，都必须归入同一个 item。
7. 背景、网格线、标注文字和不属于任何角色帧的杂点不得计入 bbox。
8. 不得仅按连通区域拆分角色；同一帧中彼此不连通但明显属于该角色的像素仍属于同一个 item。

bbox 规则：
1. bbox 必须完整包含该帧的全部有效像素，并在角色轮廓四周保留透明安全边距；宁可多保留透明区域，也绝不能贴着角色轮廓裁切。
2. 必须分别检查头顶、左右两侧和脚底四条边界。尤其要独立检查两条腿、两只脚、头发末端、武器末端、衣摆、饰品和分离像素，不得只根据身体主体或 foot_anchor 推断 bbox。
3. 如果角色靠近画布边缘，安全边距可在该侧缩小到画布边界；如果相邻角色限制了空间，应以两者之间透明间隔的中线为界，但仍不得包含相邻角色像素。
4. 不得为了让不同方向尺寸一致而统一 bbox。每个方向必须根据自己的完整轮廓和安全边距独立计算。
5. 先找出该帧所有有效像素的 xmin、ymin、xmax、ymax，再向四周加入安全边距并限制在原始画布内。bbox.x、bbox.y 使用加入安全边距后的左上坐标。
6. 加入安全边距后的最右边界记为 right，最下边界记为 bottom，则 width = right - x，height = bottom - y；right 和 bottom 是不包含端点的像素边界坐标。
7. bbox 的 x、y、width、height 必须为整数，width 和 height 必须大于 0。

脚底锚点与对齐规则：
1. foot_anchor 表示角色站立在地面上的稳定支点，必须依据脚掌与地面的实际接触位置判断。
2. foot_anchor 使用整张原始图集中的绝对坐标，不是 bbox 内的局部坐标。
3. 不得直接使用 bbox 中心、角色轮廓中心或 bbox 最下方作为脚底锚点。
4. 即使 bbox 包含低于脚底的武器、衣摆、尾巴、阴影或特效，foot_anchor 仍必须位于真实脚底接地位置；阴影和特效不得参与锚点计算。
5. 先识别承担角色体重并实际接触地面的脚，再确定锚点：
   - 如果两只脚都接触地面，x 取两只脚接地区域中心之间的中点。
   - 如果只有一只脚接触地面，x 取该脚接地区域的水平中心。
   - 如果多只脚接触地面，x 取所有承重接地区域中心的平均值。
6. foot_anchor.y 取脚底与地面接触处的水平基线。采用像素边界坐标，因此它通常等于接地鞋底最下方像素行的 y + 1。
7. foot_anchor.x 和 foot_anchor.y 可以是整数或小数；需要表达两个像素边界之间的精确中心时可以使用 .5。
8. 对所有方向必须使用同一种解剖学和几何学标准。将所有 foot_anchor 对齐到同一个目标坐标后，角色换向时脚底应保持不动。
9. 裁剪后的局部锚点由以下公式得到，但不要额外输出 local_anchor：
   local_anchor_x = foot_anchor.x - bbox.x
   local_anchor_y = foot_anchor.y - bbox.y

返回前必须自行检查：
1. image_width 和 image_height 必须与提示词末尾给出的已知实际画布尺寸完全一致。
2. 所有角色帧均已检测，且 index 顺序正确并从 0 连续递增。
3. 每个 bbox 都完整包含对应帧的全部有效像素，并已逐边确认安全边距；任何一只脚或其他突出部位都没有越过 bbox。
4. 每个 foot_anchor 都位于对应角色的真实脚底接地区域，而不是轮廓或 bbox 的几何中心。
5. 每个 foot_anchor 都严格包含 x 和 y 两个字段。

严格返回以下结构：{"image_width":整数,"image_height":整数,"items":[{"index":整数,"bbox":{"x":整数,"y":整数,"width":整数,"height":整数},"foot_anchor":{"x":数字,"y":数字}}]}。

foot_anchor 必须始终是同时包含 x 和 y 的 JSON 对象，绝不能是单个数字、数组、字符串、null 或其他结构。正确示例："foot_anchor":{"x":177.5,"y":340}。

只返回一个完整、准确、可解析的 JSON 对象。响应的第一个字符必须是 {，最后一个字符必须是 }。不要使用 Markdown 代码块，不要添加解释、标题、注释、尾随逗号或任何 JSON 之外的字符。

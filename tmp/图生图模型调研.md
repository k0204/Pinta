# 本机图生图 AI 模型调研

> 调研日期:2026-08-04 · 目标:评估当前机器能跑起来的「图生图(img2img)」AI 模型

---

## 一、本机硬件确认

| 项目 | 配置 | 评估 |
|------|------|------|
| **GPU** | NVIDIA GeForce RTX 3050,**8GB GDDR6** | 关键瓶颈。8GB 版(非 4GB)显著扩展可跑范围 |
| GPU 驱动 | 560.94 | 支持 CUDA 12.x runtime |
| 计算能力 | 8.6(Ampere) | 支持 Flash Attention / xFormers |
| **CPU** | i9-12900KF(16 核 24 线程) | 很强,CPU 推理也可用 |
| **内存** | 64GB | 巨大优势,可大量 CPU offload,几乎不会因 RAM 受限 |
| OS | Windows 10 专业版 19045 | 兼容性好 |
| CUDA Toolkit | **未安装** | 需安装,或依赖 PyTorch 自带 runtime |
| Python | 系统 3.8.10(偏老) | 建议另装 3.10 / 3.11(SD 生态主流版本) |
| C 盘可用 | 22.9GB | **偏紧**,模型文件(2-24GB)务必放其他盘 |

**核心结论:8GB 显存是门槛,64GB 内存是兜底。** 凡是量化后 ≤10GB 的模型都能跑;超过的部分靠 CPU offload 兜底(慢但能出图)。

## 二、主流图生图模型可行性分级(按本机 8GB 显存)

所有模型均原生支持 img2img(加噪去噪);ControlNet 可进一步增强图生图控制力。

### 🟢 流畅(8GB 内原生跑,秒级~十秒级)

| 模型 | 显存 | 图生图能力 | 备注 |
|------|------|-----------|------|
| **SD 1.5** | ~4GB | 原生 img2img + ControlNet + inpainting | LoRA/ControlNet 生态最丰富,512×512 秒级出图,首选 |
| **Z-Image Turbo** | ~6GB(GGUF) | img2img + 4 步快速编辑 | 2026 新模型,约 1 分钟/张,小显存友好 |
| **Flux 2 Klein 4B(FP8)** | ~6GB | img2img | 小参数 FLUX,30 秒级,画质优于 SD1.5 |

### 🟡 可跑·需优化(8-10GB,需量化/低显存模式,十秒~分钟级)

| 模型 | 显存 | 优化方式 | 备注 |
|------|------|---------|------|
| **SDXL(medvram)** | ~8GB | `--medvram` + VAE tiling | 1024×1024 可跑,速度尚可 |
| **SDXL(1024px FP16)** | ~9GB | lowvram + 降分辨率 | 基础文/图生图可,加 ControlNet 易 OOM |
| **FLUX.1 Schnell(Q4 量化)** | ~10GB | GGUF Q4 + 文本编码器 CPU offload | 可跑,提示词遵从强,文字渲染好 |

### 🟠 慢·大量 offload(12-14GB,能出图但分钟级,体验差)

| 模型 | 显存 | 备注 |
|------|------|------|
| **FLUX.1 Dev(Q5 量化)** | ~12GB | 量化 + 大量 offload,慢但画质最佳 |
| **SD 3.5 Large** | ~14GB | 量化勉强,不推荐日常用 |

### 🔴 不实际(8GB 卡基本不可行,纯 CPU 太慢)

| 模型 | 显存 | 备注 |
|------|------|------|
| FLUX.1 Dev(FP16 全精度) | ~22GB | 含 T5 文本编码器,8GB 卡不实际 |
| FLUX.2 Dev | 24GB+ | 最新最重,需 RTX 4090/5090 级 |

## 三、按场景推荐

| 使用场景 | 推荐模型 | 推荐工具 | 预期速度(本机) |
|---------|---------|---------|----------------|
| 快速图生图 / 风格迁移 / 批量变体 | **SD 1.5** | ComfyUI 或 Forge | 512² 约 3-5 秒/张 |
| 高质量图生图(写实/人像) | **SDXL(medvram)** | Forge 或 Fooocus | 1024² 约 30-60 秒/张 |
| 最佳画质 / 文字渲染 / 复杂构图 | **FLUX.1 Dev(Q4 量化)** | ComfyUI | 1024² 约 1-3 分钟/张 |
| 精灵图 / 角色一致性 | SD 1.5 + ControlNet + LoRA | ComfyUI | 秒级,可批量 |
| 无 GPU 压力 / 旧硬件兜底 | CPU 方案(Biniou) | Biniou | 512² 约 2-3 分钟/张 |

> 注:本机 64GB RAM 使 CPU offload 几乎不会因内存失败,只是慢。FLUX 量化版「能跑」主要靠这个兜底。

## 五、落地建议(若要在本机部署)

1. **环境**:装 CUDA Toolkit 12.x + Python 3.10/3.11(别用系统 3.8),建议用 venv 隔离。
2. **存储**:模型文件放 **非 C 盘**(C 盘仅剩 22.9GB)。SD1.5 约 4GB,SDXL 约 7GB,FLUX 量化版 6-12GB。
3. **起步**:用 ComfyUI + SD 1.5,最快验证流程通不通。
4. **SDXL**:启动加 `--medvram`,分辨率先 1024²,别一上来叠多 ControlNet。
5. **FLUX**:必须用 **GGUF Q4/Q5 量化版**(`unsloth` 或 `city96` 出品),配 ComfyUI 的 `enable_model_cpu_offload`,文本编码器 offload 到 CPU。
6. **通用优化**:开 xFormers / Flash Attention;大图用 Tiled Diffusion 插件突破显存限制。
7. **驱动**:560.94 已够新,无需升级。
